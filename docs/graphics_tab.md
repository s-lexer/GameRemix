# Вкладка «Графика» — что есть и как рисуем (проект, 06.11.2026)

Цель владельца: ВСЯ наша графика в одном месте, с превью (скриншотами), выбор «Оригинал» или вариант. Здесь — инвентарь того, что получилось и что можно добавить, и решение по экрану. Ничего не реализовано (дизайн-документ; перед кодом прочитать docs/design.md и согласовать с владельцем).

## 3. Экран «Графика» (предложение)
Новая страница в левой панели: «Патчи и фиксы / **Графика** / Секреты / Инструменты / Запрос игры».

Общая идея: «конструктор вида игры» — слева-сверху превью текущей сборки, ниже карточки-слоты, выбор слота меняет превью, внизу одна панель «Применить».

```
┌ Графика ────────────────────────────────────────────────┐
│ ┌─ ПРЕВЬЮ (кадр игры/окно, ползунок До|После) ───────┐   │
│ │  [ Сцена ] [ Инвентарь ] [ Диалог ] [ Карта ]      │ вкладки превью
│ │                                       ◄ До | После ►│   │
│ └────────────────────────────────────────────────────┘   │
│ 1 Картинка игры   ( Оригинал ● ) ( Чистая v2 ) ( v2.1 )  │ карточки со скрином,
│ 2 Интерфейс       ( Ориг ) ( A ) ( B ) ( C ) ( D )  [A-вар]│ чипы: «скачать 472 МБ»,
│ 3 Шрифты          [ Выбрать… ]    4 Масштаб [Авто 125%▾] │  «установлено», «нужна GPU»
│ 5 Рендер          cnc-ddraw ★ / dgVoodoo  [Настройки…]    │
│ ▸ Исправления (закат/рассвет, пол в подвале, карта)       │ переключатели
│ ▸ Лаборатория (эффекты, анимации) — скрыто по умолчанию   │
│ ───────────────────────────────────────────────────────  │
│ Изменения: Интерфейс B, Картинка v2 · 472 МБ  [Применить] [Вернуть оригинал] │
└──────────────────────────────────────────────────────────┘
```
Принципы:
- Превью КРУПНОЕ (≈55% высоты), карточки — со своим миниатюрным скриншотом (одно и то же окно во всех вариантах, чтобы сравнивать: инвентарь + фрагмент сцены).
- Выбор слота НЕ применяет сразу: накопительная панель внизу «Применить» (одним действием, с общим размером загрузки, бэкапом, откатом). Итоговый состав виден в превью (составное изображение).
- Слоты независимы, кроме правил совместимости (скин A меняет flat.cmp — несовместим с будущими «крупными окнами»; v2/скины ставятся на разные архивы; масштаб требует cnc-ddraw) — несовместимое серым + причина в подсказке.
- Статусы: «Оригинал / Установлено / Не скачано (472 МБ) / Устарело / Смешанное».
- «Вернуть оригинал» — одна кнопка (входит в «Откатить всё»).
- Игра запущена — применение запрещено (как сейчас).
- Эксперименты (шейдеры, анимации, форк) — в «Лаборатории», свёрнуто, с пометкой «пока бесполезно/нестабильно».
- Язык RU/EN; подписи карточек из манифеста.

## 4. Данные и превью
- Расширить манифест наборов (docs/asset_sets.md): kind = `sprite-set | ui-skin | scale | patch`, поля `previews=[{id,url,w,h}]`, `requires`, `conflicts`. Скин-набор — отдельные .set из scratch\ui_skins\*.
- Превью — небольшие JPEG (≈40–80 КБ, ~600×350), готовятся скриптом из реальных кадров; грузятся с сервера вместе с манифестом (кэш в %LOCALAPPDATA%), в exe встроен только «заглушка/Оригинал». Лицензия кадров — на решении владельца (см. вариант 3).
- Сравнение «До|После» — один кадр, две версии (сборка скриптом), а не живой рендер в программе.
- WinForms 3.5: свой контрол превью (owner-draw, как FontPreview), без внешних зависимостей; страница прокручиваемая (окно 1020×700, на 768 px экранах — AutoScroll).
