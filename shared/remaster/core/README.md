# Remaster.Core

Общее независимое от движка .NET8 ядро первого прототипа: целочисленная сетка, команды, BFS, детерминированные тики/RNG, собственные version1 snapshots и replay digest. В нём нет имён, файлов или смещений конкретной игры.

Исходный код подготовлен GPT-воркером C в Epic Divine Divinity; координатор вынес переиспользуемые части в shared до интеграции. Игровые допущения и RE-зависимости: `games/divine-divinity/remaster/core/`.

Проверки без сторонних test frameworks: `dotnet run --project shared/remaster/core/checks/Remaster.Core.Checks.csproj`.

Это выбранные правила прототипа. Соответствие какой-либо оригинальной игре не заявлено. Шаг симуляции должен вызываться игровым fixed-tick адаптером; графика и ввод сюда не включены.
