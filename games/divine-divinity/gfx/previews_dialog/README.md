Генерируется: `python -X utf8 games/divine-divinity/tools/make_gfx_previews_dialog.py [--font owner|orig]` (из корня проекта, Pillow + numpy; игру не запускает).
Парное к `../previews/` (инвентарь): тот же размер 600x350, JPEG <= 90 КБ, одна сцена 1920x1080 (`ui_mockups/src/common.scene_native`).

Во всех 6 кадрах одно и то же: окно диалога 580x230 на (670,725) над хотбаром, кроп (630,695,1290,1080) = 660x385 -> 600x350 (LANCZOS), портрет (архив 3 #1093), текст, перенос строк. Отличается только графика. Скрипт проверяет assert'ом, что перенос строк одинаков у всех скинов.

## Из чего собран кадр
- Окно = спрайт `8:3`, портрет `3:1093` в (17,17), кнопки `8:249/245/241` в (17,93/136/179), стрелки `8:285/297` и ползунок `8:288/291/294` по правому краю (x=548) — раскладка из `bmg\dialogpl.bmg`, форма `DualDialog`.
- Область текста берётся из bmg скина: оригинал/B/C/D — content area (10,10)-(440,190); A — (20,18)-(436,183) (его `flat.cmp`); начало текста = (80+x0, 15+y0) окна (сверено с `ui_skins/previews/A_dialog.png`).
- Текст рисуют настоящие глифы `fonts\dialog_yellow.fnt` (NPC) и `dialog_grey.fnt` (ответы) через `analysis/mlfont.py`; по умолчанию текущий набор владельца из `X:\GAMES\...\fonts` (читается, не меняется), `--font orig` — оригинальные `*-.fnt`.
- Текст: реплика NPC «Ну, ты готова отправиться в путь?» — `voice/npc_lines.csv`, Zandalor_DBINN 4029:6 (женский вариант); три ответа (один переносится на 2 строки) — как на Screenshot_10 владельца (ответы игрока в npc_lines.csv отсутствуют: там только реплики NPC).
