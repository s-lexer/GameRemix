# Превью вкладки «Графика» (окно ИНВЕНТАРЬ, «До|После»)

Генерируется: `python games/divine-divinity/tools/make_gfx_previews.py` (из корня проекта, Pillow + numpy).

Все 6 кадров — одна сцена 1920x1080 (`ui_mockups/src/common.scene_native`), одна раскладка окон, один кроп; отличается только графика.
Спрайты декодируются из собранных архивов CPacked (иконки предметов — архив 3, UI — архив 8), как в `tools/ui_skins/make_previews.py`.

| Файл | Источник архивов |
|---|---|
| inv_orig.jpg | `scratch/gfx_sets/orig` (оригинал, включая иконки предметов) |
| inv_v2.jpg | `scratch/gfx_sets/v2full` («Чистая графика v2», без скина) |
| inv_A.jpg | UI из `scratch/ui_skins/A/static/imagelists` («Пергамент») + остальное из v2full |
| inv_B.jpg | то же, скин B («Тёмный металл») |
| inv_C.jpg | то же, скин C («Оригинал HD») |
| inv_D.jpg | то же, скин D («Тёмное стекло») |

Кроп: (l,t,r,b) = (1260,190,1920,575) на сцене 1920x1080 (660x385, 12:7) -> 600x350, LANCZOS. Видны окно экипировки и инвентарь целиком.
JPEG: quality 84-88 (первое значение, при котором файл <= 90 КБ), размеры 68-90 КБ, всего ~451 КБ.

Примечание: скины A-D показаны поверх набора v2 (иконки предметов и прочее из v2full), как в make_previews.py; inv_orig целиком оригинальный.
В левом краю кадра виден краешек третьего (пустого) окна — одинаков во всех кадрах.
